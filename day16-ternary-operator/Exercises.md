# Day 16 Exercises — Ternary Operator (`?:`)

> Practice using Java's ternary operator to replace simple `if...else` statements.

---

# Exercise 1 — Pass or Fail

## Task

Create an integer named `score`.

If the score is **60 or greater**, display:

```
Pass
```

Otherwise display:

```
Fail
```

Use only the ternary operator.
